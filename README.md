# Hi, I'm Tobias

## What I do

- **Shops and integrations** - Magento 2 and Shopware 6 shops and the ERP systems behind them, built on a reusable integration toolkit instead of from scratch every time.
- **Pipelines and deployment** - CI/CD components, quality gates and deployment templates a whole team uses. Nothing goes live unchecked.
- **Architecture** - Laravel and Filament for new things, plenty of experience keeping old things alive and upgradable. Simple beats clever.
- **Technical project lead** - estimates, releases and customer calls on large shop projects. Staging first, sign-off second, live third.
- **AI tooling** - MCP servers and Claude Code setups that let developers ask their AI assistant about tickets and code.
- **People** - code reviews, onboarding, mentoring apprentices, and the one people ask when something is on fire.
